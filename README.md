# Global Superstore Sales & Profitability Analysis

## Project Overview

This project analyzes the Global Superstore dataset to evaluate sales performance, profitability, discount impact, and product-level profitability.

The analysis was conducted using Microsoft Excel, with a particular focus on identifying how discounting affects profitability in Southeast Asia.

## Business Objective

The objective of this analysis was to:

- Evaluate overall sales and profitability performance
- Identify the impact of discounts on profit
- Determine which discount levels create the greatest profitability risk
- Identify poorly performing products and sub-categories
- Provide actionable recommendations to improve profitability

## Tools Used

- Microsoft Excel
- PivotTables
- Data Cleaning
- Data Analysis
- Data Visualization

## Profitability Analysis — Southeast Asia Tables

A deeper analysis was conducted on the Tables sub-category in Southeast Asia.

| KPI | Value |
|---|---:|
| Total Sales | $52,452 |
| Total Profit | -$18,618.31 |
| Profit Margin | -35.50% |
| High-Discount Sales | 89.52% |
| High-Discount Profit | -$20,144.50 |

## Key Findings

### 1. High discounts are strongly associated with poor profitability

The Southeast Asia Tables segment generated a negative profit of $18,618.31 while 89.52% of sales were associated with the high-discount band.

### 2. High-discount transactions created substantial profit loss

High-discount sales generated approximately -$20,144.50 in profit, making excessive discounting a major profitability concern within this segment.

### 3. Product-level profitability revealed significant losses

Several Tables products generated negative profit, with some products showing extremely negative discount profit margins.

### 4. Discounting requires stronger control

The analysis suggests that discounting should not be treated simply as a sales-growth strategy. Discounts need to be evaluated against their effect on profit margins.

## Recommendations

Based on the analysis:

1. Review products receiving very high discounts and assess whether the discount levels are commercially sustainable.
2. Reduce excessive discounting where it consistently results in negative margins.
3. Introduce discount thresholds that require management review.
4. Monitor product-level profit margins rather than relying only on sales volume.
5. Investigate loss-making Tables products and determine whether pricing, cost structure, or discount strategy is responsible.
6. Prioritize profitable sales while using discounts selectively to support strategic objectives.

## Conclusion

The analysis demonstrates how Excel can be used to move from raw transactional data to business-focused insights.

The key lesson from the Southeast Asia Tables analysis is that strong sales volume does not necessarily translate into profitability. Understanding the relationship between discounts, sales, and profit is essential for making better pricing and promotional decisions.
